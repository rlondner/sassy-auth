### 🔴 PR #153 — 🎨 Palette: Enhanced table UX, fixed CI workflow, and TypeScript errors
**Author:** `google-labs-jules[bot]` · **Updated:** 2026-06-28 · **+218 / −104**, 19 files

**Findings:**
- 🔴 **Type-safety regression in auth-server transactions.** Nine `prisma.$transaction(async (tx: Tx) => ...)` callbacks were rewritten as `async (tx: any) => ...` in `roles.service.ts` (×3), `users.service.ts` (×3), and `seed/seed.ts` (×4 — including the platform super-admin role and platform org bootstrap). The original `type Tx = Parameters<Parameters<typeof prisma.$transaction>[0]>[0]` exists in the same files but is no longer referenced. This silently disables compile-time checks on every `tx.saRole.*`, `tx.saUser.*`, `tx.saPermission.*` call inside critical RBAC/identity flows, exactly where type errors should be loudest. **Fix:** use the canonical `Prisma.TransactionClient` from `@prisma/client` (or restore the `Tx` alias and resolve the underlying inference error properly — likely a Prisma client version drift, not something to mask with `any`). Until then, this PR must not merge.
- 🟡 **CI: pnpm version pin removed.** `.github/workflows/e2e.yml` drops `with: version: 9` from `pnpm/action-setup@v4`. Only safe if `package.json#packageManager` pins the version — verify and document.
- 🟡 **CI: `turbo build --filter=!@sassy-auth/auth-server`.** New build step explicitly excludes auth-server. Intent appears to be "build only what the admin Next.js bundle needs for unit/e2e", but if any e2e spec imports auth-server code paths it'll silently use stale dist. Confirm with `turbo dry-run` and gate on it.
- 🟡 **Jest a11y mocks.** `jest.setup.ts` replaces `Tooltip`/`DropdownMenu*` with `Passthrough`/`Trigger` shells. Reasonable to avoid `TooltipProvider` context errors, but tests now can't assert tooltip text or aria-described-by wiring. Consider rendering real primitives wrapped in `TooltipProvider` inside a test util instead.
- 🟢 `TooltipProvider` hoisted to `app/layout.tsx` — correct global placement.
- 🟢 Adds `aria-label={t('common.moreActions')}`, `focus-visible:ring-2` on icon buttons, and FR translations for previously-English `common.save/edit/delete/confirm`. Solid a11y+i18n win.

**Recommendation:** **Request Changes** — revert the `(tx: any)` casts before merge.
