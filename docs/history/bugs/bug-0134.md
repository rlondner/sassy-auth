# bug-0134: Permissions matrix missing apps.get operation

**Severity:** Minor
**Status:** Open

## Description

The `GATE` matrix in `permissions-matrix.ts` defines list/create/update/delete for
the `apps` area but omits `get`. The `GET /api/apps/:id` endpoint exists and is
documented but its permission check is not covered by the matrix E2E tests.

The `orgs`, `roles`, and `permissions` areas all include a `get` operation.

## Files

- `apps/auth-server/test/matrix/permissions-matrix.ts:47-53`

## Fix

Add `get` operation to the apps area:

```typescript
apps: {
  list: { method: 'GET', path: '/api/apps' },
  get:  { method: 'GET', path: '/api/apps/:id' },
  create: { method: 'POST', path: '/api/apps' },
  update: { method: 'PATCH', path: '/api/apps/:id' },
  delete: { method: 'DELETE', path: '/api/apps/:id' },
},
```
