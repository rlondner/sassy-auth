## bug-0309: staging deploy dispatches on every push to `dev`, even when no app version was bumped

**Fixed:** false

See [bug-0309.md](./bug-0309.md) for the full writeup (filed and fixed together in PR #487).

Summary: `version-bump.yml`'s `Dispatch staging deploy` step had no guard, so it ran on
every push to `dev` regardless of whether `scripts/bump-versions.mjs` actually bumped a
deployed package. Docs-only commits, CI config changes, and changes to non-deployed
packages all triggered a full staging redeploy with no version change — the commit/push
step immediately above it was already correctly guarded on
`steps.bump.outputs.message != ''`, the dispatch step just never got the same treatment.
Fixed by applying the identical guard.
