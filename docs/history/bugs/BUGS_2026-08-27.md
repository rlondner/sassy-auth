### bug-0274 🟡 Low — unit-tests workflow missed by the Node 24 migration

**Files:**
- `.github/workflows/unit-tests.yml`

**Description:** `5e21bfe` ("chore: migrate to Node 24", 2026-08-25) bumped
`e2e.yml`, `typecheck.yml`, the `Dockerfile`, and `package.json#engines` to
Node 24, stating it "Bumps CI, Docker, and engines to Node 24" — but did not
touch `unit-tests.yml`, which kept `node-version: 20`. Every run since has
logged a pnpm "Unsupported engine" warning plus GitHub's own Node-20
deprecation warning. Not a hard failure (pnpm downgrades the engines mismatch
to a warning), but it leaves the CI job most likely to catch a genuine
Node-24-only regression running on the wrong runtime. Full detail in
`bug-0274.md`.

**Fix:** PR #361. `node-version: 20` → `24`, matching the other three
migration sites. **Verified:** re-ran the full local suite this workflow
runs (`auth-server`, `admin`, `ui`, `db`) under local Node 24.14.1 — all
green, no version-attributable failures.

**Fixed:** false
