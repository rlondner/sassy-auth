# bug-0108: raceSuccessOrError in e2e page objects resolves silently when both timeout

**Severity:** Warning
**File:** `apps/admin-e2e/pages/apps.page.ts` (lines 69-90), and identically in orgs, permissions, roles, users page objects

When neither a success toast nor an alert appears, both promises settle to `null`, `Promise.race` resolves with `null`, and the function returns silently — the test passes as a false positive.

**Fix:** After `Promise.race` resolves, check `if (outcome === null) throw new Error('Neither success nor error appeared within timeout')`.

**Tests needed:** Mock a server-unreachable scenario and verify the test fails rather than passing silently.
