# bug-0096: updatePermission allows renaming to platform.* prefix

**Severity:** Warning
**File:** `apps/auth-server/src/permissions/permissions.service.ts` (lines 165-170)

`updatePermission` checks `isPlatform(existing.name)` before allowing updates but does not check if `dto.name` starts with `platform.*`. A non-platform permission can be renamed to a `platform.*`-prefixed name.

**Fix:** Add `if (dto.name && isPlatform(dto.name)) throw new ForbiddenException(...)` after the existing guard.

**Tests needed:** Unit test: attempt to rename `contracts.read` to `platform.contracts.read` — should throw.
