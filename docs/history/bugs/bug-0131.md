# bug-0131: raceSuccessOrError success text check is unscoped

**Severity:** Warning
**Status:** Open

## Description

The `raceSuccessOrError` helper in all 5 E2E page objects scopes error detection to
`[data-sonner-toaster], [role="dialog"], [role="alertdialog"]`, but the success detection
uses a bare `page.getByText(successText)` that matches anywhere on the page.

This can cause false positives if the success text appears in a table cell or page body.

## Files

- `apps/admin-e2e/pages/apps.page.ts:77`
- `apps/admin-e2e/pages/orgs.page.ts:73`
- `apps/admin-e2e/pages/permissions.page.ts:72`
- `apps/admin-e2e/pages/roles.page.ts:72`
- `apps/admin-e2e/pages/users.page.ts:92`

## Fix

Scope the success check to the Sonner toast container:

```typescript
const success = page.locator('[data-sonner-toaster]')
  .getByText(successText)
  .waitFor({ state: 'visible', timeout: 10_000 })
  .then(() => 'success' as const)
  .catch(() => null)
```
