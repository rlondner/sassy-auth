# bug-0132: user-create-drawer uses raw error string instead of i18n key

**Severity:** Minor
**Status:** Open

## Description

`user-create-drawer.tsx` uses `result.error` (raw English string) for server errors
instead of `result.errorKey` with `t()` like every other drawer. Client-side validation
messages ('Required', 'Invalid email') are also hardcoded English.

## Files

- `apps/admin/components/user-create-drawer.tsx:88-91,116-118`
- `apps/admin/messages/en.json`
- `apps/admin/messages/fr.json`

## Fix

1. Change error handling to use `'errorKey' in result` pattern
2. Replace hardcoded validation strings with `t('common.required')` / `t('common.invalidEmail')`
3. Add missing i18n keys to both locale files
