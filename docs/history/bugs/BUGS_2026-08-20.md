## bug-0263: GitHub Actions artifact storage quota exhausted — every recent e2e run fails to upload its report/traces

**Severity:** Warning
**Fixed:** false
**Fix PR:** [#341](https://github.com/rlondner/sassy-auth/pull/341)

Every sampled `admin-e2e` run in the last 48 hours (6/6 checked) fails with
`Failed to CreateArtifact: Artifact storage quota has been hit`. Root cause:
34+ days of a red e2e suite (bug-0259) combined with `retain-on-failure`
trace/video capture and 14-day artifact retention outpaced the account's
Actions artifact storage quota — no run, pass or fail, can currently upload
its Playwright report or failure diagnostics. This is actively hampering the
bug-0262 CI-flakiness investigation, since new failing runs no longer leave
traces to inspect. Fix: drop `retention-days` from 14 to 3 in
`.github/workflows/e2e.yml`. Full details in
[bug-0263.md](./bug-0263.md).
