# bug-0102: multitenant-grant-ceiling.spec.ts tests are order-dependent

**Severity:** Warning
**File:** `apps/auth-server/test/scenarios/multitenant-grant-ceiling.spec.ts`

Test 3 assumes `contracts.read` was already granted by test 1. No `afterEach`/`afterAll` teardown of direct-permission grants, so state bleeds across runs.

**Fix:** Make each test independently set the full expected state, and add an `afterAll` that resets all direct-permission grants.

**Tests needed:** Run the spec in isolation with `--randomize` flag to verify test independence.
