# bug-0101: factories.ts closeScenarioApp tears down shared NestJS server

**Severity:** Critical
**File:** `apps/auth-server/test/scenarios/factories.ts` (lines 30-32, 43-75)

`sharedApp`, `sharedHttpServer`, and `sessionCookies` are module-level singletons. When Jest runs multiple scenario spec files in the same worker, the first file's `afterAll` calls `closeScenarioApp()`, killing the server for the second spec.

**Fix:** Use a reference counter: `closeScenarioApp` only tears down when the last consumer disconnects. Or make each spec file fully independent.

**Tests needed:** Run both scenario spec files in the same Jest worker (`--maxWorkers=1`) and verify both complete successfully.
