## Fixed (1 bug)

- **bug-0287** (High) — the port-renumber commit's find/replace didn't
  stop at the port: it also swapped every `http://localhost:3000`
  default to `https://localhost:3010`, but
  `apps/auth-server/src/main.ts` never gained an `httpsOptions`/TLS
  setup — `app.listen()` is still plain HTTP. Every operational default
  (`.env.example`, `docker-compose.yml`, `docker/entrypoint.sh`, the
  `e2e.yml` workflow's own env block, the Playwright e2e fixtures'
  fallback URLs, `.flox/env/manifest.{toml,lock}`, `README.md`,
  `BEGINNER_README.md`) now points at a scheme the server doesn't
  speak, which fails the TLS handshake before any request reaches the
  app. Fixed by reverting the scheme to `http://` in the files this
  commit touched, keeping the intended port change. PR #386.
