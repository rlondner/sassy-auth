# bug-0143: deletePermission P2003 guard unreachable

**File:** `apps/auth-server/src/permissions/permissions.service.ts:189-209`

**Problem:** The P2003 catch block is unreachable because `onDelete: Cascade` on both join tables means Prisma cascades the delete before any FK violation. Permission deletion silently revokes all role/user assignments.

**Fix:** Pre-check dependent count before deleting. Block with ConflictException if in use.
