# bug-0135: user-create-drawer stale role/permission IDs on org switch

**Severity:** Info
**Status:** Open

## Description

When the user changes the org dropdown in `user-create-drawer.tsx`, role options are
refetched but previously selected `roleIds` and `directPermissionIds` are not cleared.
Stale IDs from the previous org persist in form state and could be silently submitted.

## Files

- `apps/admin/components/user-create-drawer.tsx:64-80`

## Fix

Clear `roleIds` and `directPermissionIds` when `orgId` changes:

```typescript
useEffect(() => {
  set('roleIds')([])
  set('directPermissionIds')([])
  // ... rest of the effect
}, [orgId])
```
