### PKCE-required check runs before redirect-URI ownership is validated

**Where:** `apps/auth-server/src/token/token.controller.ts`
(`oauthAuthorize`), and the equivalent `pkceRequired` computation in
`apps/auth-server/src/registration/registration.service.ts`.
**Status not fixed** — this code is **not on `dev`**. It exists only
in a local, unpushed branch (`worktree-custom-scheme-redirect-uris`,
checked out under `.claude/worktrees/custom-scheme-redirect-uris/`)
that has no open PR. A bug-NNNN + fix-PR against `dev` would have
nothing on `dev` to fix, so this is tracked in
[TODO_2026-11-19.md](../todo/TODO_2026-11-19.md) instead, for Raphael
to address before opening that branch's PR.

**Detail:** the new `pkceRequired` check is computed from the raw
`redirect_uri` query parameter before `assertRedirectUriAllowed`
confirms it belongs to the requesting app. Not confirmed exploitable
(the subsequent `assertRedirectUriAllowed` call still rejects any URI
that isn't actually registered, so no PKCE bypass was found), but the
ordering is backwards and produces the wrong error code for a
legitimate custom-scheme app given a non-matching `redirect_uri`.
**Fixed:** false
