### Legacy bug-0001 / bug-0002 / bug-0003 CHANGELOG contradiction — reconciled, closed out

`CHANGELOG.md`'s original 2026-05 "Risky patterns / missing tests" section
(end of file) still listed these three as open risk items, while a later
"Fixed" entry (`b62d543`) claimed bug-0001 was resolved — a contradiction
flagged as a carried TODO item since at least 2026-08-21 and repeated in
every subsequent run without being checked against current code. Checked
all three directly against `dev`:

- **bug-0001** (RBAC isolation) — `apps/auth-server/src/common/permissions/check-permission.ts`
  requires an explicit `targetOrgId` for any non-`platform.*` permission
  branch and throws `ForbiddenException` if the caller's `orgId` doesn't
  match it; an undefined `targetOrgId` is treated as "does not grant,"
  not "grants." **Fixed**, matches the `b62d543` changelog entry.
- **bug-0002** (invitation tokens leaking via request URL logs / Sentry) —
  `apps/auth-server/src/common/logger/request-logging.middleware.ts`'s
  `sanitizeUrlForLog` replaces the `/api/invitations/:token` path segment
  and redacts a fixed set of sensitive query keys (`token`, `code`,
  `state`, `access_token`, `refresh_token`, `client_secret`, `secret`,
  `authorization`, `password`) before any request line reaches Winston.
  **Fixed for the structured-log vector.** Did NOT verify the Sentry
  breadcrumb vector (`apps/auth-server/src/instrument.ts`'s `Sentry.init`
  has no `beforeSend`/`beforeBreadcrumb` scrubber, and Sentry's Node HTTP
  auto-instrumentation can include full request URLs in breadcrumbs) —
  left as a lower-confidence follow-up rather than closing the whole bug;
  see `TODO_2026-10-13.md`.
- **bug-0003** (admin middleware accepts any non-empty cookie value) —
  `apps/admin/middleware.ts`'s `validateSession` extracts the session
  cookie and round-trips it to the auth-server's `/api/auth/get-session`
  on every request outside the 10s cache TTL; a non-empty cookie with no
  corresponding server-side session is rejected (`ok: false` → redirect to
  `/login`). **Fixed**, matches the `b62d543` changelog entry.

Updated `CHANGELOG.md`'s legacy risk-item list to point at this
reconciliation instead of leaving the stale "must be resolved before this
branch is shippable" language standing uncontested next to a later entry
that says the opposite.
