# bug-0302 🟡 Medium — Plaintext user email logged unconditionally on every sign-in attempt (admin + auth-server)

**Fixed:** true

**Files:**
- `apps/auth-server/src/auth/auth.config.ts:347`
- `apps/admin/app/login/actions.ts:240`

**Description:** Both the auth-server's `/sign-in/email` `before` hook
and the admin console's `signInInner` server action logged the
submitted email address on every sign-in attempt, with no `NODE_ENV`
guard:

```ts
console.log(`[auth-server] Sign-in attempt for ${email ?? 'unknown'}`);
console.log(`[admin] Sign-in attempt for ${email}`)
```

A few hundred lines below in the same `auth.config.ts` file, the
magic-link URL logger is deliberately wrapped in
`if (process.env.NODE_ENV !== 'production')`, with a comment explaining
that production stdout is captured by shared log streams (Docker logs,
Sentry, Datadog) that operators and log-forwarding pipelines can read.
These two sibling log statements got no such treatment.

**Failure scenario:** In production, every login attempt — successful
or not — writes the user's plaintext email address to stdout, which
lands in whatever log aggregation pipeline is attached (Docker logs,
Sentry breadcrumbs ingestion, Datadog log pipeline). This is low
severity on its own (email addresses are not secrets in the same way a
token is), but it is unnecessary PII retention in a shared log stream,
inconsistent with the project's own stated logging policy for the
sibling magic-link case, and makes it harder to reason about what PII
actually ends up in production logs.

**Fix:** Gated both `console.log` calls behind
`process.env.NODE_ENV !== 'production'`, matching the existing
magic-link logger pattern in the same file.

**Verification:** `pnpm --filter @sassy-auth/auth-server exec jest auth.config` found no spec covering this hook directly; grepped both touched files' existing `*.spec.ts` / `*.test.ts` siblings for `Sign-in attempt` — no test asserts on this log output, so the guard is a safe, non-breaking change. Confirmed `pnpm --filter @sassy-auth/admin exec tsc --noEmit` and `pnpm --filter @sassy-auth/auth-server exec tsc --noEmit` both pass.
