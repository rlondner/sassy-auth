## Risky patterns observed

1. **`publicId: 'placeholder'` pattern** — used in all 4 entity creation flows, all seed scripts, and demo data scripts. 25+ call sites. A fundamental race condition under concurrency.

2. **No defense-in-depth on token issuance** — JWT `scope` includes all user permissions regardless of `aud` app. Token controller, OAuth service, and permission resolution each trust the layer below without independent validation.

3. **Orphaned BetterAuth identities** — `deleteUser` only removes the `SaUser` row. The BetterAuth `User`, `Account`, and `Session` rows persist indefinitely, consuming the email address and maintaining live sessions.

4. **Missing production hardening** — No Helmet, no Swagger gate, no BetterAuth session config, no magic-link/OTP production guard. Multiple small gaps that compound into a weak production posture.

5. **Admin component timer hygiene** — 13 components use uncancelled `setTimeout` for copy feedback. Consistent pattern, consistent bug — one fix template applies to all.
