## `main.ts`'s scheme silently drifted from every consumer's default (bug-0287, fixed)

Not itself a follow-up — filed and fixed as bug-0287 (PR #386) — but
worth flagging the root cause for whoever reviews that PR: a
find/replace over `http://localhost:3000` will also catch
`https://...3000` occurrences it shouldn't touch and *miss* the fact
that `3000`→`3010` and `http`→`https` are two independent axes. If a
future change actually does want local HTTPS (DEPLOYMENT.md's
`NODE_ENV=production` cookie note hints this has been a recurring
pain point), it needs `main.ts` updated with real `httpsOptions` /
dev certs (e.g. mkcert), not just a URL string change.
