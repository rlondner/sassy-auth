## Risky patterns observed

1. **Create/Update DTO parity gap** — `CreateUserDto` has `@MinLength(1)` on names but `UpdateUserDto` does not. This pattern likely exists in other entity DTOs as well (app, org, role, permission update DTOs should be audited for the same gap).

2. **No caching on middleware auth check** — Every authenticated request pays the full auth-server round-trip cost. As the admin console grows in complexity (more pages, more prefetches, more RSC data loads), this cost compounds.

3. **Dead props pattern** — `void` expressions used to silence unused-variable warnings on props suggest features that were planned but never implemented. These create false API surface area that callers may rely on.

4. **Demo code diverging from docs** — The resource server scope mismatch is easy to fix but represents a class of issue where documentation and implementation drift. The missing `getApp` endpoint is the most impactful instance.
