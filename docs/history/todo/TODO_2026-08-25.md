### 3. PR #353 (bug-0269) — run the duplicate-row pre-flight query before merging

The new `@@unique([providerId, accountId])` migration on `Account` will hard-fail on
apply if any duplicate rows already exist in a non-dev database. Run this against
every non-dev environment before merging:
```sql
SELECT "providerId", "accountId", COUNT(*)
FROM "Account"
GROUP BY 1, 2 HAVING COUNT(*) > 1;
```
