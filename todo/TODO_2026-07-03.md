## Risky patterns observed

1. **Missing `cancelled` flag in async useEffects** — 6 components lack it (4 tables, 2 view drawers). Inconsistent with `role-create-drawer` and `user-create-drawer` which correctly implement the pattern.

2. **Create vs. Edit drawer validation asymmetry** — Create drawers consistently validate `!name.trim()` but edit drawers skip validation entirely. Systemic gap across `AppEditDrawer` and `OrgEditDrawer`.

3. **No error boundaries for auth pages** — `/login`, `/accept-invite`, `/oauth-error` routes have no `error.tsx`, falling through to unstyled `global-error.tsx`.

4. **Promise.all without .catch()** — Multiple places in `user-view-drawer.tsx` and `user-create-drawer.tsx` use `Promise.all(...).then(...)` with no `.catch()`, producing unhandled rejections when API calls fail.
