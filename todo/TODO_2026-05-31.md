If the auth server ever emits a non-standard cookie value, the entire `signIn` action crashes with a 500 instead of returning an error to the form. Tracked as **bug-0022**.
- [ ] **Agent worktree submodule artifacts in git** — 5 `.claude/worktrees/agent-*` entries were committed as submodules via merge commit `51074b0`. These are ephemeral and will cause `git clone` warnings about missing submodule repos. Tracked as **bug-0023**.
- [ ] **Shadcn reskin is a large migration** — The implementation plan has 30+ tasks. Key risk: `@sassy-auth/ui` re-exports will change, and every consumer in `apps/admin` must be updated atomically. Consider a feature flag or incremental migration strategy (wrap old components in shadcn-compatible adapters).
