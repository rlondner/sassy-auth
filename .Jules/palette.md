## 2025-05-30 - Button Loading Pattern
**Learning:** Consistent loading states on action buttons prevent double-submissions and provide immediate feedback for async operations. Using `aria-busy` and `disabled` together ensures both visual and assistive technology users understand the state.
**Action:** Use the `loading` prop on `Button` for all Server Action or API-bound submissions.
