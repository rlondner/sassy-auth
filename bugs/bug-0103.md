# bug-0103: permissions-table.tsx has no canWrite prop

**Severity:** Warning
**File:** `apps/admin/components/permissions-table.tsx` (line 21)

`PermissionsTable` has no `canWrite` prop. Edit/delete actions are controlled solely by `isImmutable` (system/platform name detection), not by the caller's actual write permissions.

**Fix:** Add a `canWrite` prop to `PermissionsTable` (matching the pattern in `RolesTable`), and conditionally render edit/delete actions only when `canWrite` is true.

**Tests needed:** Unit test: render `PermissionsTable` with `canWrite=false` — edit/delete actions should not appear.
