# bug-0106: admin layout.tsx uses notFound() instead of redirect for unauthenticated sessions

**Severity:** Warning
**File:** `apps/admin/app/(admin)/layout.tsx` (line 28)

When a session is not found, the layout calls `notFound()`, which renders a 404 page. An unauthenticated user sees "Page not found" with no guidance.

**Fix:** Replace `notFound()` with `redirect('/login')`.

**Tests needed:** E2E test: visit `/users` without a session — should redirect to `/login`, not show a 404.
