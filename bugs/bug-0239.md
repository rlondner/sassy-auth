# bug-0239: French locale regressed to English for user CRUD toasts and the "Resend" action

**Severity:** Warning
**Area:** admin / i18n (fr)
**Files:**
- `apps/admin/messages/fr.json:404` (`users.actions.resend`)
- `apps/admin/messages/fr.json:407-410` (`users.toast.created`, `.updated`, `.deleted`, `.resent`)

Five user-facing strings in the **French** message catalog contain the **English** copy
instead of a translation:

| key | `fr.json` value (wrong) | should be (approx.) |
|-----|-------------------------|---------------------|
| `users.actions.resend` | `"Resend Invitation"` | `"Renvoyer l’invitation"` |
| `users.toast.created` | `"User created"` | `"Utilisateur créé"` |
| `users.toast.updated` | `"User updated"` | `"Utilisateur mis à jour"` |
| `users.toast.deleted` | `"User deleted"` | `"Utilisateur supprimé"` |
| `users.toast.resent` | `"Invitation resent"` | `"Invitation renvoyée"` |

Adjacent keys (`resetLinkGenerated`, `activated`, `deactivated`) are correctly translated,
so this is a partial-translation slip introduced with the user-lifecycle actions feature
(`6ca2d12`, 2026-07-09) — the same class of defect previously fixed under **bug-0112**
(`fix/bug-0112-french-toast-i18n`). A French operator creating, updating, deleting, or
re-inviting a user sees an English toast.

**Fix:** Translate the five strings in `fr.json`.

**Tests needed:** Add a lint/test that fails when a `fr.json` leaf value is byte-identical
to its `en.json` counterpart within the `users.toast.*` / `users.actions.*` subtrees — this
would have caught both this regression and bug-0112.

**Fixed:** false
