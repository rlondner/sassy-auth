# bug-0254: Duplicate PR — #324 re-implements PR #316's `common.moreActions` aria-label localization (same 5 tables, same message keys) while #316 is still open → guaranteed merge conflict

**Severity:** Medium (PR hygiene / duplicate work — recurring Jules generation pattern)
**Status:** Open
**Fixed:** false
**Introduced by:** PR **#324** (`palette/localize-table-row-actions-aria-label-14231760063474182685`, Jules bot) — opened 2026-08-15 07:36 UTC. Overlaps the still-open PR **#316** (`palette/accessible-table-tooltips-…`, open since 2026-08-13).

## Description

PR #324 changes the `more_vert` row-action button in all five admin tables from a hardcoded
`aria-label="more actions"` to `aria-label={t('common.moreActions')}`, and adds the
`common.moreActions` key to both `apps/admin/messages/en.json` and `fr.json`. It also fixes the
top-level `common` block in `fr.json` (`save/edit/delete/confirm` were English placeholders →
`Enregistrer/Modifier/Supprimer/Confirmer`).

**Every one of those edits is already present, byte-for-byte on the same lines, in the still-open
PR #316:**

| Change | PR #324 | PR #316 |
|--------|---------|---------|
| `aria-label={t('common.moreActions')}` on the 5 tables' `more_vert` button | ✅ | ✅ (same 5 lines) |
| `common.moreActions` added to `en.json` + `fr.json` | ✅ | ✅ |
| `fr.json` top-level `common` block translated to French (fixes [bug-0244](./bug-0244.md)) | ✅ | ✅ (identical values) |
| `common.copy` / `common.copied` keys + copy-button localization + `title=` | ❌ | ✅ |
| `apps/auth-server` `auth.config.ts` `autoSignIn:false` + 3 seed `twoFactorPromptedAt:new Date()` | ❌ | ✅ ([bug-0250](./bug-0250.md) 🔴, [bug-0251](./bug-0251.md) 🟡) |

So PR #324 is a **strict, de-scoped subset** of PR #316's admin-UI work — the same idea
re-generated as a narrower PR. Both are open and both edit the identical
`<button aria-label=…>` lines across `apps-table.tsx`, `orgs-table.tsx`,
`permissions-table.tsx`, `roles-table.tsx`, `users-table.tsx` plus the same two message files, so
**whichever merges second will conflict** on every one of those hunks.

This is the same duplicate-generation pattern already filed as [bug-0245](./bug-0245.md)
(redundant Jules PR) and [bug-0248](./bug-0248.md) (triplicate password-toggle PRs #294/#296/#306):
Jules keeps opening a fresh PR for a UI concern that an earlier, still-unmerged PR already covers,
because none of its prior output ever merges (`master` frozen at `a78d4a7` since 2026-07-15).

## Why this is a bug (and not just noise)

1. **Guaranteed merge conflict** between two of the repo's own open PRs on ~7 files.
2. **Wasted review + reviewer confusion** — two PRs claiming to "localize table row action
   accessibility," one a subset of the other.
3. **A genuine fork in the decision**, because the two PRs are *not* equivalent:
   - #324 is **clean** — admin-only, and it carries the `fr.json` `common` fix (bug-0244) **without**
     the Critical bug-0250 seed-2FA-suppression payload that blocks #316.
   - #316 does **more** (copy-button `copy`/`copied` localization) but is **blocked** by bug-0250
     and the bug-0251 scope creep.

## Files (overlap set)

- `apps/admin/components/apps-table.tsx`, `orgs-table.tsx`, `permissions-table.tsx`,
  `roles-table.tsx`, `users-table.tsx` — `more_vert` trigger `aria-label` (same line in both PRs)
- `apps/admin/messages/en.json`, `apps/admin/messages/fr.json` — `common.moreActions` +
  `common` French fix (identical additions in both PRs)
- `apps/admin/components/__tests__/apps-table.test.tsx` — #324's added assertion (see
  [bug-0255](./bug-0255.md) for the coverage gap)

## Suggested fix

Pick **one** carrier per concern; do not merge both:

- **Land the safe a11y/i18n slice via #324** (it has no auth/seed payload) — this closes
  [bug-0244](./bug-0244.md) and localizes the row-action label without dragging in bug-0250.
- **Reduce #316 to only its unique, safe delta** (the copy-button `copy`/`copied` localization),
  after stripping the `apps/auth-server` `auth.config.ts` + seed edits per
  [bug-0251](./bug-0251.md), and rebasing it onto whatever #324 lands. Or close #316's a11y half
  entirely and re-file the copy-button localization on top of #324.
- **Add a Jules guardrail:** skip generating a PR whose file/line set is already covered by an open
  `palette/*` PR (cf. the same recommendation in [bug-0248](./bug-0248.md)).
