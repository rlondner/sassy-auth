# bug-0244: French locale `common.*` action labels are untranslated English (`save`/`edit`/`delete`/`confirm`)

**Severity:** Minor
**Area:** admin / i18n (fr)
**Files:**
- `apps/admin/messages/fr.json:15-19` (`common.save`, `common.edit`, `common.delete`, `common.confirm`)

The shared `common` action labels in the **French** catalog contain the **English** copy:

| key | `fr.json` value (wrong) | should be (approx.) |
|-----|-------------------------|---------------------|
| `common.save`    | `"Save"`    | `"Enregistrer"` |
| `common.edit`    | `"Edit"`    | `"Modifier"`    |
| `common.delete`  | `"Delete"`  | `"Supprimer"`   |
| `common.confirm` | `"Confirm"` | `"Confirmer"`   |

These are the generic button labels reused across dialogs and drawers, so a French operator
sees English on core Save/Edit/Delete/Confirm controls app-wide. This is the same class of
partial-translation slip as **bug-0112** and **bug-0239** (which covered the `users.toast.*`
/ `users.actions.*` subtree) — this entry is the **`common` subtree**, still open.

Notably, the 2026-07-20 `useCopyFeedback` localization commit (`c55d026`, PR #285) added a
correctly-translated `common.copyError` (`"Échec de la copie …"`) **directly beside** these
four keys, yet left them in English — reinforcing that a byte-identical-value lint is needed.

**Fix:** Translate the four `common.*` values in `fr.json`.

**Tests needed:** Add the i18n lint proposed in bug-0239 — fail when a `fr.json` leaf value
is byte-identical to its `en.json` counterpart — and extend it to cover the `common.*`
subtree so this whole class is caught mechanically.

**Fixed:** false
