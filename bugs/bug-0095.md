# bug-0095: TOCTOU race in OAuth authorize vs code exchange

**Severity:** Warning
**File:** `apps/auth-server/src/token/token.controller.ts` (lines 107-116, 207-213)

User org/app membership is not re-validated when exchanging the authorization code. Moving a user between orgs between authorize and exchange produces a JWT with mismatched org/app claims.

**Fix:** At exchange time, after fetching `saUser`, verify `saUser.org.appId === app.id`. Reject with `UNAUTHORIZED_CLIENT` if the check fails.

**Tests needed:** E2E test: authorize as user in org A, move user to org B, exchange code — should fail.
