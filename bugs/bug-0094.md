# bug-0094: checkPermissionForApp silently grants access when targetAppId is undefined

**Severity:** Critical
**File:** `apps/auth-server/src/common/permissions/check-permission-for-app.ts` (line 51)

When `targetAppId` is `undefined`, `checkPermissionForApp` returns early without verifying app scope. Any caller holding a non-platform permission is unconditionally granted access regardless of which app the resource belongs to.

**Fix:** Change the `undefined` check to throw `ForbiddenException('targetAppId is required for non-platform permission checks')` or require `targetAppId` as a non-optional parameter.

**Tests needed:** Unit test: call `checkPermissionForApp` with `targetAppId: undefined` and a non-platform caller — should throw, not pass.
