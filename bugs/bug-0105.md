# bug-0105: permission-view-drawer.tsx fetch error silently swallowed

**Severity:** Warning
**File:** `apps/admin/components/permission-view-drawer.tsx` (lines 36-38)

If `getPermissionAction` returns an `ErrorResult`, `setDetail` is never called and the drawer stays empty with `loading = false`. No error state or message is shown.

**Fix:** Check for `'errorKey' in res` and display an error banner in the drawer body when the fetch fails.

**Tests needed:** Unit test: mock `getPermissionAction` to return `{ errorKey: 'forbidden' }` and verify an error message is rendered.
