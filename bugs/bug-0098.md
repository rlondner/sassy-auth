# bug-0098: Migration isSystem bulk UPDATE not scoped to platform app

**Severity:** Warning
**File:** `packages/db/prisma/migrations/20260618220100_.../migration.sql` (lines 4-6)

`UPDATE "SaPermission" SET "isSystem" = true WHERE "name" LIKE 'org.%'` affects all apps, not just the platform app. Non-platform apps with `org.*`-prefixed permissions get incorrectly marked as system permissions.

**Fix:** Scope the update: `WHERE "name" LIKE 'org.%' AND "appId" = (SELECT id FROM "SaApp" WHERE "isPlatform" = true)`.

**Tests needed:** Create a non-platform app with an `org.custom` permission before running the migration — verify it is NOT marked `isSystem`.
