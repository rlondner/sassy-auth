# bug-0111: me.controller unsafe cast to extract betterAuthUser from request

**Severity:** Minor
**File:** `apps/auth-server/src/me/me.controller.ts` (line 7)

`(req as unknown as Record<string, { id: string }>)['betterAuthUser'].id` — if `BetterAuthGuard` fails to attach `betterAuthUser`, this cast produces a `TypeError`. Should use optional chaining for defense-in-depth.

**Fix:** `const userId = (req as any)?.betterAuthUser?.id; if (!userId) throw new UnauthorizedException();`

**Tests needed:** Unit test: call `getMyProfile` with a request missing `betterAuthUser` — should throw `UnauthorizedException`.
