# bug-0133: roles.service.spec.ts double-awaits rejects on same promise

**Severity:** Minor
**Status:** Open

## Description

The `deleteRole` P2003 test awaits `.rejects` on the same promise reference twice:

```typescript
const promise = makeService().deleteRole('ba-caller', 'sq_r1');
await expect(promise).rejects.toBeInstanceOf(ConflictException);
await expect(promise).rejects.toMatchObject({ message: expect.stringContaining('3 users') });
```

This is unreliable across Jest versions — the first await consumes the rejection.

## Files

- `apps/auth-server/src/roles/roles.service.spec.ts:392-398`

## Fix

Use a single assertion:

```typescript
await expect(makeService().deleteRole('ba-caller', 'sq_r1')).rejects.toMatchObject({
  constructor: ConflictException,
  message: expect.stringContaining('3 users'),
});
```
