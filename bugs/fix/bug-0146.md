# bug-0146: Sentry breadcrumb logs raw user email (PII)

**File:** `apps/admin/lib/api.ts:36`

**Problem:** `createUser` breadcrumb includes `result.user.email`. All other breadcrumbs use `publicId` or opaque IDs. Sends PII to third-party service.

**Fix:** Replace `result.user.email` with `result.user.id`.
