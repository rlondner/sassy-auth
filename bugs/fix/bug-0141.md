# bug-0141: Edit drawers allow whitespace-only name submission

**Files:** `app-edit-drawer.tsx:44-49`, `org-edit-drawer.tsx:35-39`

**Problem:** Create drawers check `!name.trim()` but edit drawers don't. A single space bypasses HTML `required` and submits an empty name.

**Fix:** Add `if (!name.trim()) return` to edit drawer submit handlers.
