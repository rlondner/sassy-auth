# bug-0138: removeRole unhandled P2025 causes 500

**File:** `apps/auth-server/src/users/users.service.ts:381`

**Problem:** `removeRole` has no try-catch for Prisma P2025 (RecordNotFoundError). Returns raw 500 with stack trace when removing an unassigned role.

**Fix:** Catch P2025, throw `NotFoundException('Role is not assigned to this user')`.
