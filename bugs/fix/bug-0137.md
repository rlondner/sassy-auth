# bug-0137: Table search useEffects lack request cancellation

**Files:** `apps-table.tsx`, `orgs-table.tsx`, `permissions-table.tsx`, `roles-table.tsx`

**Problem:** Debounced search effects clear the timeout but don't cancel in-flight requests. Stale responses can overwrite newer data.

**Fix:** Add a `cancelled` flag to each effect, matching `role-create-drawer.tsx` pattern.
