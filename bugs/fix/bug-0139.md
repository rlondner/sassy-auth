# bug-0139: resendInvitation expire+create non-atomic

**File:** `apps/auth-server/src/users/users.service.ts:536-547`

**Problem:** `resendInvitation` expires old tokens then creates a new one as separate Prisma calls outside `$transaction`. Partial failure orphans the user with zero valid tokens.

**Fix:** Wrap both operations in `prisma.$transaction()`.
