Key Relationships

sa_user.betterAuthUserId → user.id 1:1 — links SassyAuth profile to BetterAuth identity
sa_user.orgId → sa_org.id N:1 — user belongs to exactly one org
sa_org.appId → sa_app.id N:1 — org is scoped to one app
sa_permission.appId → sa_app.id N:1 — permissions scoped per app (platform app = platform perms)
sa_role.appId → sa_app.id N:1 — roles scoped per app, reusable across orgs of same app
sa_role_permission → role + permission M:N — roles bundle permissions
sa_user_role → user + role M:N — users assigned roles (additive)
sa_user_permission → user + permission M:N — direct permission grants (additive)

Bootstrap: Platform App & Org

On first run, seed: sa_app { isPlatform: true, name: "SassyAuth", url: "..." }
Then seed: sa_org { isPlatform: true, name: "Platform", appId: platformApp.id }
Platform permissions (e.g. platform.orgs.manage) seeded with appId = platformApp.id — immutable
